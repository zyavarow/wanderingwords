# Wandering Words

A personal vocabulary app for Android: two words a day (Monday–Saturday) from a hand-picked list of 1,053, a Night Glass home-screen widget, and a 7:00 am notification. Sunday is review day.

Every push to `main` builds a signed `WanderingWords.apk` and attaches it to a new release. Download it on your phone from the latest release to install or update.

See HANDOFF.md for the full project documentation.
